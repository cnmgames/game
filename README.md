# 情侣互动小游戏合集

一比一复刻 lovegame.hoothin.com 的情侣互动游戏网站。

## 包含游戏

- ✈️ 情侣飞行棋 - 双人对战，步步甜蜜
- 🎡 真心话大冒险转盘 - SVG转盘旋转动画
- 🎲 情趣骰子 - 喝酒助兴，挑战点数
- 🦁 火辣暗兽棋 - 翻牌记忆配对，输家惩罚
- 🎰 桃色老虎机 - 地点动作部位随机组合，欲望条进度
- 💎 午夜大富翁 - 棋盘冒险，事件触发

## 特性

- 深色玻璃拟态风格，极光背景动画
- 卡片 hover 悬浮、emoji 旋转放大动画
- 在线人数模拟波动
- 左下角 PWA 脉冲安装按钮
- 全设备响应式适配
- 纯前端，可部署到 GitHub Pages

## 本地运行

```bash
npm install
npm run dev
```

访问 http://localhost:3000/game

## 部署到 GitHub Pages

1. 推送到 main 分支
2. Settings → Pages → Source 选 GitHub Actions
3. 等待 Actions 自动构建部署
4. 访问 https://你的用户名.github.io/game/
